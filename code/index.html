    Cette courte étape non notée vous permet de tester la détection d'erreurs au clic et le format du questionnaire avant les 3 textes officiels.

    Consignes de la relecture :

    Vous allez lire un court texte de pratique (environ 65 mots). Dans ce texte, 2 erreurs ont été insérées (par exemple un mot en double ou une faute d'accord).

    • Repérer une erreur : Dès que vous voyez une erreur, cliquez uniquement sur le mot erroné (un seul mot par erreur) avec la souris. Il deviendra surligné en rouge.
    • Annuler une sélection : Si vous avez cliqué sur un mot par inadvertance, recliquez dessus pour le désélectionner.
    • Validation : Lorsque vous avez terminé votre relecture, cliquez sur le bouton « Terminer l'entraînement » en bas de page.
    • Compréhension : Vous répondrez ensuite à 2 questions à choix multiples pour tester le format du questionnaire.

    Prenez tout votre temps pour bien comprendre le fonctionnement du clic. Lorsque vous êtes prêt, cliquez sur le bouton ci-dessous.

    Bilan de votre pratique :

    À quoi s'attendre pour l'expérience officielle :

    L'expérience comprend 3 blocs de lecture d'environ 300 mots chacun. Chaque bloc testera une modalité de lecture différente :

    • Lecture silencieuse : Vous lisez dans votre tête à votre rythme habituel.
    • Lecture à voix haute : Vous lisez à voix haute de manière claire et continue.
    • Lecture assistée par synthèse vocale (TTS) : Vous écoutez le texte au casque pendant que vous le suivez des yeux.

    Avant chaque texte, un écran de consigne vous indiquera quelle modalité adopter. Cliquez simplement sur chaque erreur que vous repérez au fil de votre lecture.
